## Findings, ranked by cost × frequency

### F1 — the shell runs on the render task (SHELLTASK) — seconds, every typed verb
`unaos/crates/kernel/src/main.rs:2766` (`handle_key` → `shell::dispatch_command`, Origin::Door) and `main.rs:6958`
(the dock's verb: `dispatch_command` inline on the render loop). Rule: R86 (a key ≤ 1 ms), R88 (input never blocked).
The code: every shell line — `tests usbnet7`, `tests play flac`, the storm — runs to completion on the render task; the
compositor, the cursor and every queued key wait. The wire: `render=handler render_ms=7595.7` (12:43:32, `tests usbnet7`),
21 stalls over 1 s totalling 64.5 s; DECJOBHANG's "the shell never returned" took the render task's handler with it
("something in the tests stole focus"). **Fix (arc):** the shell's dispatch on its own task (the decoder-job shape,
`hda_play`'s `tq_tick` queue): the render task posts the line and repaints the console from the term ring as output
lands; a verb that needs the panel takes it through `SCREEN_APP_ACTIVE` as today. Cost × frequency: seconds × every verb.

### F2 — 4 s of every boot in two trackpad control timeouts (TPMODE) — 4 s × every boot
`unaos/crates/kernel/src/drivers/ehci/mod.rs:4815` (`bcm5974_mode_attempt`), called from `bcm5974_mode_switch` (:4791).
Rule: BOOT80 (the boot's own time line), R96 (lean). The code tries the conformant `wIndex = intf` first: the GET times
out (2 s) and the SET times out (2 s) on 5/5 flown boots (`GET_REPORT(feature) addr=9 intf=1 widx=1 FAILED (timeout)`,
then `SET_REPORT … FAILED (timeout)`), and `trackpad-armed` lands at 6.0 s against `kbd-armed` at 2.2 s, right before the
takeover. **Fix (arc):** a 100 ms bound on these two probes (a device that answers does so in one frame), or try the
index that latched last (the readback's `[tp] mt route` is the evidence) first; witness: `trackpad-armed` ≤ 2.5 s.

### F3 — four String allocations and seven locks per render pass for the session name — PATCHED 384db2e6
`unaos/crates/kernel/src/prefs.rs:388` (`ensure_loaded`), `video/settings.rs:360` and `:376` (`user_name()` twice),
`video/loginitems.rs:97`. Rule: the review's §2 (a String per tick), QUERYFOLDER's counter model. Each pass of the desktop
chain (`console_launch_drain` → `quarry::service` → `live::service` → `settings::service` → prefs/login items) built the
session name as a `String` to compare it with the last one. **Fix (patch, behaviour-neutral):** `prefs::user_name_in`
reads `whoami` into a stack buffer; a `String` is made only when the session changed. Owed (arc SESSIONGEN): a login
generation atomic in `fs/users.rs` (two writers, :856 and :975) so the three compares become one relaxed load.

### F4 — the association seed re-reads 1191 blocks on every boot (ASSOCSTAMP) — 1.7 s × every boot
`unaos/crates/kernel/src/fs/users.rs:3237` (`step=assoc-seed`). Rule: BOOT80 (its own FAIL: `ms=353 … types=26 -> FAIL`).
A reboot with nothing to create still reads 1191 blocks (`created=0 ms=1662`). **Fix (arc):** one stamp (the seed table's
hash, as an attribute on the types directory) read first; equal ⇒ skip the walk. Witness: `step=assoc-seed ms<100 created=0 stamp=hit`.

### F5 — every serial line costs the render task; the wire is 15 % keystroke echoes (WIREDIET) — per key, per second
`unaos/crates/kernel/src/main.rs:3577` (`usbdebug_event_print`, on `gui_recv_blocking_x86`): one `USB-DEBUG: KEY` line per
key — 2634 of 17915 flown lines. The per-second rollups `[vugfps]` 1339, `:: VUGART:` 909, `[wc-h]` 740, `[wpace]` 708,
`:: BPACE:` 595 are another 4291. Rule: QUIETBOOT (R86's bound), R96. **Fix (seat + arc):** drop `usbdebug` from the metal
knob line (it is a debugging knob riding every flight); the rollups print on change or every 5 s, not every second.
WIFI5's captures (`wifi/bringup/capture.rs:63–105`, the d11 MMIO and the ucode pre-image as rows) run only on the armed
`wifi3` boot — name that boot's numbers as not comparable with the others.

### F6 — the compositor allocates four buffers per pass before it knows anything is dirty (COMPSCRATCH)
`unaos/crates/kernel/src/video/wm.rs:5569` (`paint` Vec, every pass with a sprite), `:5920` (`dirty_pre`, `bands_pre`,
plus the `RowsSnap` copy of the whole table), `:5970` (`order` + a sort), `:6072` (`seed` clone under `witness`), then
an O(n²) occlusion walk over every row. Rule: the review's §2 (allocation in the frame). Bounded by `slots()` (the
high-water mark, ~10–20 rows flown), so microseconds per pass, ×60–125 passes a second. **Fix (arc):** the four
scratch buffers pooled beside `SNAP_POOL` (the `RowsSnap` shape), and an early return when no row is damaged before the
snapshot.

### F7 — `service_damage` walks the table under its lock on every flush when idle (DAMAGEGEN)
`unaos/crates/kernel/src/video/wm.rs:4029`. Every `pal.render()` (`Screen::flush`) takes the window-table lock and scans
every row for `damaged`. **Fix (arc):** a damage generation bumped at the five `.damaged = true` sites; the idle check is
one relaxed load.

### F8 — six service passes take a spin lock to find an empty latch (SVCLATCH)
`video/player.rs:309`, `video/textedit.rs:114`, `video/facet.rs:1087` and `:1091`, `video/fileview.rs:173`,
`video/launcher.rs:875`, `video/quarry/attrcols.rs:231` (locks, drains and `collect`s an empty Vec). Rule: QUERYFOLDER's
counter model (a quiet pass is one atomic load). **Fix (arc):** each latch gains a `POSTED: AtomicBool` set by the
producer; the pass returns on a relaxed load.
