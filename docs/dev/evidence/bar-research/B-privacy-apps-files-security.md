# Research B: privacy, the app model, files, security people can live with

Status of each UnaOS mechanism at 1719fe54 (from the blueprint sheets): **built** = in the tree, with the gate or test named. **ruled, unbuilt** = ruled but not in the tree. **proposal** = this report's suggestion, which needs a seat decision or a ruling.

## 0. The owner's two (verbatim, named first)
| what they do wrong | evidence | what UnaOS does instead | the measurable bar |
|---|---|---|---|
| "locking people into hardware and software that's been given an expiration date the user is not privileged to. when the company decides to axe a thing that's it, consumer be damned" | Sonos "recycle mode" deactivated working speakers 21 days after a trade-up [18]. Spotify bricked Car Thing on 2024-12-09 and told owners to throw it away [19]. Windows 11's TPM 2.0 and CPU floor plus the end of Windows 10 support on 2025-10-14 leave ~240M working PCs stranded (Canalys) [20]. FTC "Nixing the Fix" (2021) found "scant evidence" for repair restrictions [21]. Product shutdown lists such as Google's are long. Each iOS release drops older devices | proposal (owner-stated): nothing in the OS phones home to stay alive (no licence check, no activation, no cloud-backed feature). Every feature works offline. A 2012 laptop is a first-class target (the rMBP track is that machine). The bunker keeps proprietary bits the user already owns (firmware, codecs) on their disk, so a vendor shutting down cannot remove them | NIC-absent fixture: boot rMBP 2012 + full handler smoke with network unplugged → every feature passes. Count of "requires internet" refusals = 0. Grep gate: no expiry date or remote-revocation check in the tree |
| "the whole 'i know better than the user so i will not even let them attempt this thing'" | Sequoia removed Gatekeeper's Control-click override [22]. SIP can be turned off only from Recovery. Leaving Windows S mode is one-way, and in S mode only Store apps run [23]. Built-in apps that cannot be removed. Settings that updates put back. "This app can't be opened" | ruled design: Helm's pass/ask/refuse (BP-handlers-7, Helm not yet linked in the kernel), where REFUSE is reserved for physical harm. Everything else is ASK: the risk is stated once, then the user's word is final and Principia stores it, so updates never reset it (BP-storage-11: a refused file is never overwritten). Built: BP-security-9's one ask for a foreign program | fixture per wall (unsigned ELF, overwrite /apps item, remove a bundled app): outcome is ASK, not REFUSE. After "yes" the action runs, and after a reboot and an update the choice is still stored (re-ask count = 0). Refusals outside Helm's physical domain = 0 |

## 4. Privacy and respect
| what they do wrong | evidence | what UnaOS does instead | the measurable bar |
|---|---|---|---|
| Telemetry is on by default, users cannot see what it contains, and consent is not valid | Dutch DPA ruled in 2017 that Windows 10 telemetry broke Dutch privacy law (Full level on by default) [1] | proposal: no telemetry code path exists. Vein runs only when a caller needs it (BP-handlers-8, R82) and no handler has a background uploader | idle-boot fixture: boot, log in, leave idle 1 h. Count of `[net]` connect lines not caused by a user verb = 0 (read with awk on `target/serial*.log`) |
| Ads in the shell: "recommendations" in the Start menu | KB5036980 put Microsoft Store app promotions in the Windows 11 Start menu [2] | proposal: the shell's furniture draws only the user's own objects. No remote content source is wired into video/furniture | grep gate: no URL or http_core call reachable from `video/**` furniture. Desktop capture after first boot shows only local items |
| Account required to use your own computer | Microsoft removed `bypassnro` and "known mechanisms for creating a local account" in Setup [3] | built: the first user is a local principal created on the machine. Users live in `/USERS.DAT`, and setup needs no network (BP-security-3, BP-storage-13) | twoboot boot 1 with the NIC absent reaches `[login] session open user=… role=admin` |
| An always-on screenshot memory of everything the user sees | Recall kept an OCR database that other code running as the same user could read in plain text (Beaumont 2024). A 2026 proof of concept still extracted the data [4] | built in part: capture is per user and on demand only. Root takes no screenshots (BP-security-8, R67). proposal: no periodic capture API | `tests prtscr`: no-session capture = refused. grep gate: no timer-driven caller of capture |
| Nagging and dark patterns (confirmshaming, hard-to-find opt-outs, prompts that keep coming back) | FTC staff report "Bringing Dark Patterns to Light" (2022) [5]. macOS Sequoia asks again every month to keep allowing screen recording [6] | proposal: a decision the user made is stored once in Principia's store (`<home>/settings/<domain>`) and never asked again unless the user revokes it | fixture: grant, reboot 3 times, advance the clock 90 days. Prompt count = 0 |

## 5. The app model
| what they do wrong | evidence | what UnaOS does instead | the measurable bar |
|---|---|---|---|
| Uninstalling leaves files behind (registry entries, `~/Library`, dotfiles) | Everyday experience on all three platforms. The tree treats `<home>/.name` dotfiles as a defect | built: a preference lives only in Principia's store, and the gate fails on dotfile literals (BP-security-10, BP-storage-11). proposal: an app is one directory under `/apps` plus its settings domain | fixture: install, run, uninstall, then diff the file tree. Leftover files = 0 outside the user's own documents |
| Permission prompts users cannot understand | Felt et al. 2012: 17% paid attention to Android permissions and 3% answered all comprehension questions correctly [7] | built: every program is a principal with explicit grants, checked at one `SYS_OPEN` lookup (BP-security-1). design text: "ask on use" (permission_model §2). A grant is a handle to the file the user picked, not a category like "Storage" | an app opens a file it was not handed → `-EPERM`, and the refusal appears on the wire. Prompt text is a fixture string a reviewer checks (verb + object) |
| Sandboxes that break apps | macOS App Translocation runs downloaded apps from a hidden random path, which breaks updaters and causes crashes [8] | built: a program on a foreign volume is asked about ONCE (Copy to Apps / Open / Cancel), runs from RAM and writes nothing (BP-security-9). It is not moved behind the user's back | `tests apptrust`: one ask, then the program runs at its stated path. A program copied to `/apps` asks 0 times after that |
| App stores as gatekeepers (fees, anti-steering) | EU DMA fine of €500M on Apple (Apr 2025) [9]. Apple found in willful violation of the Epic injunction [10] | built: no store is needed. A program sighted on a removable volume opens after one ask, and the administrator's authority (not a vendor's) decides `/apps` (BP-security-3) | an unsigned ELF on a USB stick → Copy to Apps → it runs, with 0 network calls |
| Dependency hell: a binary built for one Linux distro fails on another | Torvalds, DebConf14: "you make binaries for Fedora 19, Fedora 20…" [11] | built: a single una-abi plus bus verbs, and handlers share one `no_std` core (BP-handlers-4). proposal: an app is statically linked against una-abi only | an ELF built at abi vN runs unchanged on the next 3 tagged builds (fixture ELF kept in the tree) |
| Admin prompts as reflexive UAC clicks | Windows UAC and macOS password sheets for routine actions | built: root has no password and cannot log in. Only install, the updater and the boot-FAT unlock need the administrator (BP-security-3, -7) | count of admin asks during a normal session = 0. They appear only for install or update |

## 6. Files and data
| what they do wrong | evidence | what UnaOS does instead | the measurable bar |
|---|---|---|---|
| Cloud sync moves your files without asking | OneDrive Known Folder Move redirects Desktop and Documents. Users report "my files are gone" [12] | built: ONE namespace with no hidden second copy (BP-storage-1). proposal: Junct and other sync only mount under `/volumes/<remote>`, never redirect `/home` | `tests rootdisk` plus: no path under `/home/<u>` resolves to a non-root backend |
| Hidden folders and scattered locations | `AppData`, `~/Library`, `~/.config` | built: one root, `/home/<name>` spelled by `users::home_of`. Root links are only `boot` and `volumes` (BP-storage-2, -13) | ROOTDISK2 `links=volumes-only`. A hidden-entry count under `/home/<u>` other than `.Trash` = 0 |
| Search fails until you rebuild the index by hand | Sequoia reports: Spotlight finds no files until `mdutil -E` is run [13] | built: the UnaFS name index is built in chunks at login, never at boot (BP-storage-8). proposal: the index is updated in the same transaction as the write, so it cannot drift | `tests nameindex`. Fixture: create 10k files, then search → 10k hits and 0 misses, with no rebuild step |
| Metadata lost when files cross filesystems (macOS `._` files, xattrs dropped on FAT and zip) | Common experience. The FAT and exFAT boundary drops xattrs | proposal: Geode `.geode` archives carry UnaFS records whole. A copy to FAT warns before it drops anything | round-trip test: UnaFS → .geode → UnaFS gives byte-identical records |
| Trash behaves differently by app and by volume | Explorer and Finder Trash differ for removable, network and terminal deletes | built: `trash_core` is the one Trash both rings share, at `/home/<u>/.Trash/` (BP-storage-14). proposal: Midden `rm` goes to the same Trash | `tests trash`: delete from Quarry and from Midden → both appear in one listing, and both restore to their original paths |

## 7. Security that users can live with
| what they do wrong | evidence | what UnaOS does instead | the measurable bar |
|---|---|---|---|
| Passwords are reused and phished. Passkey flows differ from site to site | FIDO 2025: 93% sign-in success with passkeys. SOUPS 2025 found passkey UX varies a lot across 111 sites [14] | built: Holocron is the one keyring in ring 3 (holocron_core). The kernel only does KDF (BP-security-11). proposal: Holocron is the passkey authenticator for Aether | Aether WebAuthn fixture: register, then sign in, with 0 typed secrets |
| Encryption is opt-in, or on by default with the key held by the vendor | Windows 11 24H2 turns on BitLocker and uploads the recovery key to the Microsoft account. Losing the account means losing the data [15] | proposal: UnaFS volume key wrapped by the Argon2id(`SYS_KDF`) of the login secret, with the recovery key shown and printed locally, never uploaded | fixture: pull the disk and mount it on the host `tools/unafs` → refused without the key. Count of network sends of the key = 0 |
| Weak password storage and online guessing | Common breach finding | built: no plaintext anywhere, and each guess costs about 250 ms of PBKDF2, with one answer for every refusal (BP-security-2, -4) | timing fixture: 100 wrong guesses ≥ 25 s. Refusal text is identical for "no such user" and "wrong password" |
| Security that works but nobody ships (Qubes, seL4, Fuchsia) | Qubes needs a VM per domain. seL4 is proven correct but is only a microkernel. Fuchsia shipped only on Nest Hub [16][17] | built: capabilities first, handles checked at one lookup point, and system trees owned by `system` (BP-security-1, -6). The model is the desktop default, not an expert mode | `tests rootacl` anon_write=refused. A handle forged in ring 3 → `-EPERM` |
| A workaround that turns protections off (disabling SIP, SELinux permissive) | Common advice in support forums | built: weakening SMEP, NXE, WXN or page permissions is a STOP tripwire (BP-security-12) | WXAUDIT-CORES line is present and clean on every boot. Open item: aarch64 WXN is not enabled yet |

**The three decisions that matter most.** (1) **One authority for each thing, with no shadow copies.** The mount table owns names, Principia owns settings, Holocron owns secrets and `trash_core` owns Trash. Most of the other OSes' failures in this report come from a second place where things pile up: AppData and dotfiles, a OneDrive redirect, a Spotlight index that drifts, a Recall database. When there is only one place, a test can count what is left over and expect zero. (2) **The grant is the object the user picked, not a category.** A handle-capability per file or device, checked at one `SYS_OPEN` point, makes a prompt answerable ("Stria wants *this file*"), lets the program stay where it is, and needs no store as gatekeeper. That replaces Android's 3% comprehension and macOS's monthly re-asks with zero re-asks. (3) **The machine is the user's: nothing leaves it by default, and nothing in it expires or refuses.** This means no account at setup, no telemetry path, no remote content in the shell, and encryption keys wrapped locally from the login secret. Each of these is checked by counting network calls on the idle-boot serial log, so "respect" becomes a number the bench can fail. The same rule covers the owner's two rows: a feature that needs the vendor alive, or a refusal that is not about physical harm, fails the NIC-absent and the ASK fixtures.
