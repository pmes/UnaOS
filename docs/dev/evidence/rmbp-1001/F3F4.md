# F3F4 — the attribute catalog on the B+tree, ordered indexes, queries that return paths (B302)

Branch `exec-rmbp-f3f4`, cut from 55352efc. Host-native: `unaos/libs/fs/unafs`, `tools/unafs`,
`tools/unafs_bench` (+ a one-word call-site rename in `handlers/vein`). No kernel file. No knob.

## Finding (audit rmbp-0929 §2, B295; B292 for timestamps)

The catalog was a flat `Vec<CatalogEntry>` rewritten whole on every `set_attribute` (O(n));
`QueryOp` had `Eq|Neq|Gt|Lt|SimilarityGt` only; every non-`Eq` op read every inode carrying the
key; `query` returned `(Inode, f32)` with no path; secondary filters were String `==` only.
`btree.rs` (F3) existed and nothing consumed it. `Inode` had no timestamps.

## The seam

The crate itself is the seam (`unafs` is the shared `no_std` core the kernel and the host tools
both link). Nothing new is built in the kernel: ATTRSURF consumes `QueryHit.path` and drops its
v1 reverse walk; UNAFSTIME's crate half is this arc's M4 (the kernel half — stamping from its
clock via `unafs::clock::set_clock_hook`, and `DirEnt.mtime` from `UnaFS::stat` — is owed to it).

## Format v6 (ONE bump for M1–M4)

* The superblock version becomes 6 (`VERSION_INDEXED`). v3/v4/v5 still mount read/write on the
  flat catalog they were written with (the K8 card keeps working); `tools/unafs migrate` replays a
  v3–v5 image into a fresh v6 one (`legacy::migrate_k8_into`), as it already did for v2.
* The catalog inode (id 2) no longer holds a list: its data is a 40 B hand-packed
  **catalog record** `UNAFSCX1 | eq_root | ord_root | entries | fnv` naming two B+tree roots. The
  trees' node blocks go through the same `RefMap` (`DeviceStore`), so every public op is still ONE
  transaction made durable by the one root-sector flip (root → imap → catalog inode → record →
  tree roots). Snapshots reach the trees through the retained imap the same way, so a snapshot
  pins the index as-of; `snapshot_blocks` and fsck's reachability walk count the tree blocks.
* **Equality tree** key `key_hash(8 BE) ‖ val_hash(8 BE) ‖ inode_id(8 BE)`, empty value.
* **Ordered tree** key `key_hash(8 BE) ‖ tag(1) ‖ ordered bytes ‖ inode_id(8 BE)`; tag 1 Int
  (sign-flipped BE), 2 Float (total-order bits BE), 3 String (bytes, NUL escaped `00 FF`, capped at
  96 bytes, terminated `00 00`, or `00 01` = spill marker when truncated). Blob/Vector are
  equality-only.
* **Inode meta trailer** (v6 inode blocks only): after the inode's unchanged bincode bytes, a
  hand-packed `UNAFSMT1 | parent | ctime | mtime | atime | name_len | name` (name ≤ 255 B, else
  `0xFFFF` and the path falls back to the parent's listing); the spill trailer, if any, follows it.
  `Inode`'s bincode encoding is unchanged (the new fields are `serde(skip)`), so every kept golden
  holds; the trailer is magic-discriminated exactly like the spill trailer.

## Milestones

* **M1 — F3 wired.** `set_attribute` = remove the old value's keys + insert the new ones, log time;
  `remove_attribute`/`unlink`/`rmdir` scrub by the inode's own keys; batch inserts into the trees
  once-per-batch record write. Catalog record KAT; power-cut-mid-insert test (old or new, never
  hybrid); snapshot pins the old index; fsck counts tree blocks and scrubs dead ids from the trees.
* **M2 — F4 real.** Ordered tree; grammar `== != > < >= <=`, `k BETWEEN a AND b`, `a <= k <= b`,
  `AND`/`OR` with parentheses, every predicate typed (Int/Float compare numerically across types;
  equality stays typed). Index scans give a candidate superset per predicate (AND intersects, OR
  unions); every candidate is verified against the real values. Vector similarity stays a scan of
  the inodes carrying the key (no ANN index).
* **M3 — paths.** `query` returns `Vec<QueryHit { inode_id, path, score }>`; the path is derived
  from the meta trailer in O(depth) inode reads; `mkdir`/create/batch stamp it, `rename` rewrites
  it, fsck checks it (`bad_parent_links`) and repair restamps. Pre-v6 volumes derive paths by one
  name-tree walk per query. `query_inodes` keeps the old `(Inode, f32)` shape for vein/bench.
* **M4 — timestamps.** `ctime` (metadata change), `mtime` (data change), `atime` (stamped only at
  create/write — reads never write under CoW: noatime) in the same trailer; `clock::now()` =
  embedder hook, else `SystemTime` under `std`, else 0. `UnaFS::stat(id)` exposes them.

## Witness

Host only (R78: no QEMU, no metal for a host-native arc): `cargo test -p unafs`,
`cargo check -p unafs --no-default-features --target aarch64-unknown-none-softfloat`,
`cargo test -p unafs-cli`; `tools/unafs query 'size >= 10 OR kind == "doc"'` prints `id path score`.

## Owed

* Kernel: the K3 witness's bit2 is `version == VERSION`, so a v5 card reads FAIL there until the
  card is re-imaged or migrated (`unafs migrate --from v5.img --to v6.img`), or the bit is relaxed
  to `MIN_SUPPORTED_VERSION..=VERSION` (UNAFSX86/ATTRSURF's file, not this arc's).
* Kernel: install `clock::set_clock_hook` from the RTC; map `stat().mtime` into `DirEnt.mtime`.
* F5 live queries; an ANN index for vectors; F6 B+tree directories (the same `btree.rs`).
