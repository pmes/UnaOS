# AETHERSTYLE3 — the modern-page CSS the engine refused (LEDGER SR103)

Charter: **Aether** owns the Web (docs/CODEX.md §2). Seam `shared-core`: css_core (parser, cascade) and
layout_core (declarations, layout, the timing model, the filter and scroll models) are no_std + alloc and linked
by both rings — handlers/aether and crates/user-aether; svg_core (no_std, SVGCORE SR52) runs the filter
primitives through layout_core. The host face (handlers/aether/src/{css,render,layout,lib.rs}) paints, routes
input and drives frames. Parent row: SR95 (AETHERSTYLE2), whose owed list this arc takes.
