# AETHERSTYLE3 — the modern-page CSS the engine refused (LEDGER SR103)

Charter: **Aether** owns the Web (docs/CODEX.md §2). Seam `shared-core`: css_core (parser, cascade) and
layout_core (declarations, layout, the timing model, the filter and scroll models) are no_std + alloc and linked
by both rings — handlers/aether and crates/user-aether; svg_core (no_std, SVGCORE SR52) runs the filter
primitives through layout_core. The host face (handlers/aether/src/{css,render,layout,lib.rs}) paints, routes
input and drives frames. Parent row: SR95 (AETHERSTYLE2), whose owed list this arc takes.

Status words: nothing here has run. Every row below is compiled code on `exec-host-aetherstyle3` (base
abcb8d33) with one fixture test written per feature; the tests, WPT and EYES are the seat's at the fold (R107).

## What the fold should see

`cargo test -p layout_core --tests` runs six new files — `filter`, `scroll`, `multicol`, `writing`, `container`,
`anim` — one test each, over the shared harness `tests/common/mod.rs` (an arena DOM that is both
`layout_core::DomNode` and `css_core::matching::Element`, fixed-advance fonts: a character is half its font size,
ascent 0.8 em, descent 0.2 em). The aethergen ledger lines this arc retires: `property:column-*`,
`property:writing-mode`, `property:transition*`, `property:animation*`, `property:filter`,
`property:backdrop-filter`, `property:container*`, `property:contain`, `at-rule:@keyframes`,
`at-rule:@container`.
