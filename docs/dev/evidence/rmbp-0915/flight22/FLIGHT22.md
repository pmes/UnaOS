## 2. Findings
- **R86 / INSTALLBARE (the ruling)**: under the password setter — `[login] set-password screen open` at 04:54:26, first key at 04:54:53 — the wire shows: `[dock] quit app=shell … win=3 -> TORN-DOWN` (a shell window WAS minted, then swept), `[wc-d] valve CLOSED` at 04:54:24 and `valve OPEN resumed suspended=15 after 29027ms closed` at 04:54:53 — the compositor valve was shut for 29.0 s and the first key landed the second it reopened; 39 `[net]` + 18 `[usbnet]` + bthid HCI + wifi2/wifi4 rungs + `[status] poll` ran under the setter. Boot 2 at the login screen: `[login] installer: stage=desktop (R77: the desktop ignites)` fires even though FIRSTBOOT said `stage=login-screen`; `[wc-x] desktop-app … /STAT.ELF` launches, a shell window is minted and torn down again, `[hda] probe deferred-start` + 37 hda lines, 127 `[net]` lines, 61 status/bthid/wifi lines — "stat and glass are open along with the login dialog". The taskbar shadow Peter saw both times is the furniture being minted before the sweep.
- **QUIETBOOT FAIL**: `lines=384 bound=250 census=0`, `top=[kepler:263,igpu-dpy:35,igpu:21,bt-l0:11,[vfs]:6,[:5,EHCI-HID:5,SPLASH:3]` — the nine recon knobs are off and the count fell 1327→384; the Kepler takeover prose alone (263) is above the bound.
- **CLOCKCANNED**: `tests sntp` on metal → `:: [sntp-x86] pre-existing anchor left in place (canned value overwrote it — operator should re-setdate) ::` — the fixture's canned packet SET THE LIVE CLOCK: the kernel stamps jumped 05:13 → 15:30 and the bar read "wed 22 jul 15:33". Boot 2 came back at 05:57 (the RTC was not written). The flight-21 "time set correct" was the RTC; NETCLOCK PASSed its poll budget but no real time arrived (`[sntp] target=0.0.0.0 from=none`, `SOCK-5: dhcpv4 no offer`). A test must never set the live clock from a fixture.
- **USBNET7 still unread**: `USBNET: … link=up speed=1000 usb=ss rx=35 tx=215 rx_ok=35`, but `USBNET6: … frames=0 … reason=no-frame-5s -> FAIL`, `USBNET7: rx_ok=35 first_frame_ms=none ethertype=none -> FAIL` — 35 receive completions, zero frames in them. The dongle was in from power-on (Peter).
- **KVBLANK8 rung 3**: `armed_by=compositor irq=1 vbl_delta=60 ratio_pct=1 kept=0 why=below-90pct -> FAIL`, `lost_at=msi isr_calls=0 eoi=ok rearm=ok -> FAIL` — the display's vblank bit is set every frame (`disp_set_no_isr=60`) and no ISR ever runs; the MSI never arrives.
- **SELFBUILD2/3/4/5 all FAIL on metal** (they were gated in QEMU): `LINUXABI: SYSKAT2.LNX exit=TIMEOUT syscalls=27 ms=20050 blocked=futex(202)`; `SYSKAT3.LNX exit=TIMEOUT syscalls=5 blocked=pread64(fd=0)`; `SYSKAT4.LNX exit=1` with `cow=fail(1) cow_kernel=fail(255) cow_prot=fail(15) shared_fork=fail(21) exec_lazy=fail(255) sigbus=fail(41)` and `RUST.LNX exit=FAULT(vec=14 cr2=0x88)`; `SELFBUILD5: mremap=fail(exit=FAULT(vec=14 cr2=0x0)) altstack=fail(exit=FAULT(vec=14 cr2=0x0)) lld=skip`. - **NOTICEKEYS**: every notice (`NOTICE-OPEN: title=Program stopped`, `title=holocron lines=2`) takes the keyboard while open (`[login] key taken by the screen`), and the holocron "started w/pid" notice "opens and closes in a flash" — four seat-typed lines (`tests selfbuild5`, `tests lumen`, `holocron put …`, `lumen`) vanished into them and had to be retyped.
