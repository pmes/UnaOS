# BP-vug — Vug, the 3D handler: CAD and Design → Make (read at c2d86af47)

## 1. What it is
- CODEX §2: Vug (3D) is "CAD viewing, editing, and CAM/Slicing"; CODEX §5 the Hardware Protocol: Vug computes the toolpath, Helm holds the wheel, Comscan pumps the stream; "no file exporting, no slicer app".
- At the read: `handlers/vug` is a rendering prototype (`handlers/vug/src/renderer.rs` a GTK4 GL cube; `handlers/vug/src/viewport.rs` a wgpu triad, not linked), 475 lines, no ignite, no bus; `temple_core` (SR147) is the one Vug core in the tree (the TEMPLE renderer). No geometry kernel, no sketch, no mesh I/O, no CAM exists.
- The probes are Sonde's: `probe_core` holds the depth scale, the pinhole intrinsics and `point_cloud` (`unaos/libs/media/probe_core/src/depth.rs:122`); the D435i path (kernel UVC + xHCI isochronous, B534, SR92, SR101, SR105) is fixed-unflown: every flight to date reads `:: SONDE: dev=none … -> SKIP(no-device) ::`.
- The program (docs/dev/USERLAND/VUG.md, Peter 2026-11-01: "making sure UnaOS becomes people's go-to for CAD … bake the concept of direct manufacturing in"): the CAD cores under `unaos/libs/cad/` — `geom_core`, `sketch_core`, `mesh_core`, `brep_core`, `scan_core`, `make_core` — `no_std` + `alloc`, `forbid(unsafe_code)`, the midden_core shape (BP-handlers-4); the handler, the faces and the kernel link them.

## 3. Seams
- Sonde -> Vug: `SMessage::ProbeFrame` (`handlers/sonde/src/lib.rs:145`) carries a depth frame with its scale and intrinsics; scan_core consumes probe_core frames, never the bus.
- Vug -> Helm -> Comscan: make_core emits `Program` (the machine-neutral IR) and ONE dialect writer per controller family; Helm's review reads the `Program` and the `Machine`, never the text.
- Vug -> euclase / quartzite: mesh_core tessellation at `f32` for the viewport; the faces hold no geometry of their own.
- Vug -> Aulë: none at the read (CODEX §4 binds Aulë in the background of a CAD project; what it builds there is unruled).

## 4. Wire
No kernel wire at the read. Host: `cargo test -p geom_core`, `-p sketch_core`, `-p mesh_core`, `-p make_core` (each crate's own suite is its witness until a face exists).

## 5. Ruled, unbuilt / owed
- VUG-MESH (LEDGER SR466): BUILT — `unaos/libs/cad/mesh_core` (no_std + alloc, forbid(unsafe_code), libm): `Mesh` (f64 positions, `[u32; 3]` triangles) with `validate(Tol)` (NonFinite / IndexOutOfRange / Degenerate / Duplicate named), the ONE degenerate definition (height over the longest edge <= `Tol.lin`), face and angle-weighted vertex normals, `aabb`, `area`, signed `volume` (closed only), `euler_characteristic`, `boundary_loops`, `weld(Tol)` (a 27-cell spatial hash, first-come representatives), `remove_degenerate`; `HalfEdge::build` (twins by sorted edge keys; NonManifold / Inconsistent / NonManifoldVertex named); `Bvh` (median split, iterative) with `pick` -> `Hit { t, tri, bary }`; `to_f32_buffers`, the one render conversion (BP-vug-1); `stl` (binary decided by length first, ASCII), `obj` (v / vt / vn / f, negative indices, groups, fan triangulation), `ply` (ascii and both binary orders read, binary little-endian written), every refusal named; exercised by `cargo test -p mesh_core`. Its geometry seam `unaos/libs/cad/mesh_core/src/geom.rs` is a marked shim of geom_core (SR464) until that folds: the swap is one file. Owed: VUG-3MF (no zip container reader exists in the tree; deflate is `pixel_core::inflate::inflate_raw`, so a zip core over it comes first), VUG-MESH-BOOL (mesh booleans, manifold the reference), VUG-MESH-GLTF (glTF export), and per-vertex scan confidence beside `Mesh` (VUG-SCAN-1, BP-vug-5).
- VUG-SKETCH (LEDGER SR465, BUILT fixed-unflown): `sketch_core` (`unaos/libs/cad/sketch_core/src/solve.rs`) — Point / Line / Circle / Arc over one f64 parameter vector, nineteen constraints with exact analytic Jacobian rows, ONE weighted min-norm Levenberg-Marquardt step for `solve` and `drag` (the under-determined minimum move; the dragged point weighted), the ordered Gram-Schmidt rank naming the later-added constraint: redundant named in `Solved.redundant` (`solve_strict` refuses it), conflicting refused by name, `dof` naming the free entities; `profiles` outer CCW with holes CW and exact areas; exercised by `cargo test -p sketch_core`. Owed: the geom_core swap of the `unaos/libs/cad/sketch_core/src/geom.rs` shim (VUG-GEOM), VUG-SKETCH-INFER (the face proposes constraints, this core only solves them), VUG-SKETCH-SPLINE (B-spline and ellipse entities; crossing loops detected, assumed absent now), a sparse solve past a few hundred parameters.
- VUG-MAKE (LEDGER SR467, BUILT): `make_core` — the planner, never the executor (no clock, no stop authority: E-stop / STO / limits hardwired, ISO 13849): `Machine` (MDES-shaped axes, the one power axis, envelope, safe Z, ISO 13399 `Tool`, `Stock`, `Fixture` keep-outs), `Op` (Drill and Contour generated; the rest refuse by owed id), the `Program` IR with `plan::durations` (trapezoid, rest to rest), `Program::validate` and `review` (refusals and asks by name), `gcode::write` / `read` for grbl 1.1 (with `Realtime`), Marlin 2, LinuxCNC; `unaos/libs/cad/make_core/src/geom.rs` is a one-file shim until VUG-GEOM folds. Owed: VUG-HELM, VUG-COMSCAN, VUG-MAKE-POCKET, VUG-MAKE-SLICE, VUG-MAKE-ADAPTIVE, VUG-MAKE-SIM (G83 rapid re-entry), VUG-MAKE-PROBE, VUG-MAKE-LOOKAHEAD, VUG-MAKE-LASER, VUG-MAKE-QUEUE, VUG-MAKE-STEPNC, VUG-MAKE-MDES.
- VUG-GEOM (LEDGER SR464, BUILT): `unaos/libs/cad/geom_core` — `Tol` (1e-6 mm, 1e-9 rad), `Vec2` / `Vec3` / `Mat3` / `Mat4` / `Quat` (euclase's names in f64, `to_f32` at the render seam only), `Transform` (rigid + uniform scale), `Interval`, `Aabb2` / `Aabb3`, Ray / Line / Segment / Plane / Circle2 / Arc2 / Circle3, `orient2d` / `orient3d` / `incircle` (Shewchuk's stage-A filter + an exact expansion fallback after one power-of-two rescale; `Predicate::Uncertain` names the only refusals, never a wrong sign), the closed-form intersections and closest points with named outcomes, polygon area / centroid / `is_ccw`; exercised by `cargo test -p geom_core`. Owed: VUG-GEOM-ADAPT (Shewchuk's adaptive stages B-D, the same signs faster), VUG-GEOM-INSPHERE, VUG-GEOM-IA (interval arithmetic with outward rounding, for brep_core and the SDF cross-check), VUG-GEOM-CURVE (bezier / NURBS evaluation, with brep_core).
- VUG-BREP-1 (LEDGER SR468, in flight): `brep_core` — topology (vertex, edge, loop, face, shell, solid) over the analytic surfaces (plane, cylinder, cone, sphere, torus) and lines / circles / NURBS curves, the validator, primitives, extrude and revolve of a sketch `Profile`, mass properties, tessellation into mesh_core with a stated chord error; VUG-BREP-2 booleans, VUG-BREP-3 fillets and chamfers, VUG-STEP (AP242), VUG-3MF (owed).
- VUG-SCAN-1 (LEDGER SR469): BUILT `scan_core` — a block-sparse projective TSDF (8³ blocks along each ray's ±trunc band, an atomic integrate of one probe_core Z16 frame with its camera-to-world pose; confidence is the observation weight), marching cubes with the 256 cases generated from a face rule (watertight, edgeTable KAT against Bourke) into a mesh with per-vertex confidence and TSDF normals and the probe's intrinsics (BP-vug-5), plane / cylinder RANSAC on Schnabel's minimal sets with rms / max / inlier residuals, and the synthetic depth fixture (`fixture::render_depth` through probe_core's pinhole model, σ ∝ z²); exercised by `cargo test -p scan_core` (geom_core / mesh_core shimmed in src/geom.rs and src/mesh.rs until folded). Owed: VUG-SCAN-POSE (frame-to-model ICP + the IMU gravity prior: the pose the fixture gives is what a metal run must estimate), VUG-PROBE (the first D435i metal frame; SR105 fixed-unflown, the bench), VUG-SCAN-SKETCH (sketch recovery on a fitted plane), VUG-SCAN-DEVIATION (the made part against its model), VUG-SCAN-SHAPES (sphere / cone / torus and Schnabel's multi-shape detect loop).
- VUG-FACE-1 (LEDGER SR470): BUILT — `vessels/vug-view`, the host viewport in facet-view's shape on quartzite's image surface (macOS first; the AppKit lines read-checked only): mesh_core is its only geometry through ONE file (`src/model.rs`: the readers, weld, aabb, `to_f32_buffers`, `Bvh::pick`), the camera is euclase's f32 math, every colour palette_core's; a SOFTWARE rasteriser (`src/raster.rs`: back-face cull, 1/z buffer, flat shade with a key light, hemisphere ambient and silhouette darkening, a 10 mm / 1 mm ground grid faded by footprint, an axis triad, the picked face in the accent) because gpu_view forwards no input to a vessel and euclase has no depth or mesh pipeline; `src/view.rs` orbits about the cursor's hit point (else the centre), pans and zooms to the cursor, Home / front / right / top, presets una (default), SolidWorks, Fusion, Blender, Onshape as (button, modifiers) tables with Alt+Left as the middle button (today's surface wire is left-only); exercised by `cargo test -p vug-view` (a headless cube to pixels and PNG). Owed: VUG-FACE-GPU (an euclase lit mesh pipeline with depth on gpu_view with camera input forwarded; the Retina-size frame needs it), VUG-FACE-BUTTONS (quartzite image_view right / other mouse buttons, wheel dx and magnify forwarded, a `button` field on bandy BrowserButton), VUG-FACE-2 the sketch face, VUG-FACE-ELF the ring-3 face, VUG-FACE-GTK, VUG-FACE-PEN.
- VUG-DOC: the text document and its reader / writer; VUG-HELM: Helm levels `make_core::review`; VUG-COMSCAN: the stream to a serial controller with grbl ok / ack (owed).
