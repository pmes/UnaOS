# BP-vug — Vug, the 3D handler: CAD and Design → Make (read at c2d86af47)

## 1. What it is
- CODEX §2: Vug (3D) is "CAD viewing, editing, and CAM/Slicing"; CODEX §5 the Hardware Protocol: Vug computes the toolpath, Helm holds the wheel, Comscan pumps the stream; "no file exporting, no slicer app".
- At the read: `handlers/vug` is a rendering prototype (`handlers/vug/src/renderer.rs` a GTK4 GL cube; `handlers/vug/src/viewport.rs` a wgpu triad, not linked), 475 lines, no ignite, no bus; `temple_core` (SR147) is the one Vug core in the tree (the TEMPLE renderer). No geometry kernel, no sketch, no mesh I/O, no CAM exists.
- The probes are Sonde's: `probe_core` holds the depth scale, the pinhole intrinsics and `point_cloud` (`unaos/libs/media/probe_core/src/depth.rs:122`); the D435i path (kernel UVC + xHCI isochronous, B534, SR92, SR101, SR105) is fixed-unflown: every flight to date reads `:: SONDE: dev=none … -> SKIP(no-device) ::`.
- The program (docs/dev/USERLAND/VUG.md, Peter 2026-11-01: "making sure UnaOS becomes people's go-to for CAD … bake the concept of direct manufacturing in"): the CAD cores under `unaos/libs/cad/` — `geom_core`, `sketch_core`, `mesh_core`, `brep_core`, `scan_core`, `make_core` — `no_std` + `alloc`, `forbid(unsafe_code)`, the midden_core shape (BP-handlers-4); the handler, the faces and the kernel link them.

## 3. Seams
- Sonde -> Vug: `SMessage::ProbeFrame` (`handlers/sonde/src/lib.rs:145`) carries a depth frame with its scale and intrinsics; scan_core consumes probe_core frames, never the bus.
- Vug -> Helm -> Comscan: make_core emits `Program` (the machine-neutral IR) and ONE dialect writer per controller family; Helm's review reads the `Program` and the `Machine`, never the text.
- Vug -> euclase / quartzite: mesh_core tessellation at `f32` for the viewport; the faces hold no geometry of their own.
- Vug -> Aulë: none at the read (CODEX §4 binds Aulë in the background of a CAD project; what it builds there is unruled).

## 4. Wire
No kernel wire at the read. Host: `cargo test -p geom_core`, `-p sketch_core`, `-p mesh_core`, `-p make_core` (each crate's own suite is its witness until a face exists).

## 5. Ruled, unbuilt / owed
- VUG-MESH (LEDGER SR466): BUILT — `unaos/libs/cad/mesh_core` (no_std + alloc, forbid(unsafe_code), libm): `Mesh` (f64 positions, `[u32; 3]` triangles) with `validate(Tol)` (NonFinite / IndexOutOfRange / Degenerate / Duplicate named), the ONE degenerate definition (height over the longest edge <= `Tol.lin`), face and angle-weighted vertex normals, `aabb`, `area`, signed `volume` (closed only), `euler_characteristic`, `boundary_loops`, `weld(Tol)` (a 27-cell spatial hash, first-come representatives), `remove_degenerate`; `HalfEdge::build` (twins by sorted edge keys; NonManifold / Inconsistent / NonManifoldVertex named); `Bvh` (median split, iterative) with `pick` -> `Hit { t, tri, bary }`; `to_f32_buffers`, the one render conversion (BP-vug-1); `stl` (binary decided by length first, ASCII), `obj` (v / vt / vn / f, negative indices, groups, fan triangulation), `ply` (ascii and both binary orders read, binary little-endian written), every refusal named; exercised by `cargo test -p mesh_core`. Its geometry seam `unaos/libs/cad/mesh_core/src/geom.rs` is a marked shim of geom_core (SR464) until that folds: the swap is one file. Owed: VUG-3MF (no zip container reader exists in the tree; deflate is `pixel_core::inflate::inflate_raw`, so a zip core over it comes first), VUG-MESH-BOOL (mesh booleans, manifold the reference), VUG-MESH-GLTF (glTF export), and per-vertex scan confidence beside `Mesh` (VUG-SCAN-1, BP-vug-5).
- VUG-SKETCH (LEDGER SR465, BUILT fixed-unflown): `sketch_core` (`unaos/libs/cad/sketch_core/src/solve.rs`) — Point / Line / Circle / Arc over one f64 parameter vector, nineteen constraints with exact analytic Jacobian rows, ONE weighted min-norm Levenberg-Marquardt step for `solve` and `drag` (the under-determined minimum move; the dragged point weighted), the ordered Gram-Schmidt rank naming the later-added constraint: redundant named in `Solved.redundant` (`solve_strict` refuses it), conflicting refused by name, `dof` naming the free entities; `profiles` outer CCW with holes CW and exact areas; exercised by `cargo test -p sketch_core`. Owed: the geom_core swap of the `unaos/libs/cad/sketch_core/src/geom.rs` shim (VUG-GEOM), VUG-SKETCH-INFER (the face proposes constraints, this core only solves them), VUG-SKETCH-SPLINE (B-spline and ellipse entities; crossing loops detected, assumed absent now), a sparse solve past a few hundred parameters.

Owed: VUG-HELM, VUG-COMSCAN, VUG-MAKE-POCKET, VUG-MAKE-SLICE, VUG-MAKE-ADAPTIVE, VUG-MAKE-SIM (G83 rapid re-entry), VUG-MAKE-PROBE, VUG-MAKE-LOOKAHEAD, VUG-MAKE-LASER, VUG-MAKE-QUEUE, VUG-MAKE-STEPNC, VUG-MAKE-MDES.
- VUG-GEOM (LEDGER SR464, BUILT): `unaos/libs/cad/geom_core` — `Tol` (1e-6 mm, 1e-9 rad), `Vec2` / `Vec3` / `Mat3` / `Mat4` / `Quat` (euclase's names in f64, `to_f32` at the render seam only), `Transform` (rigid + uniform scale), `Interval`, `Aabb2` / `Aabb3`, Ray / Line / Segment / Plane / Circle2 / Arc2 / Circle3, `orient2d` / `orient3d` / `incircle` (Shewchuk's stage-A filter + an exact expansion fallback after one power-of-two rescale; `Predicate::Uncertain` names the only refusals, never a wrong sign), the closed-form intersections and closest points with named outcomes, polygon area / centroid / `is_ccw`; exercised by `cargo test -p geom_core`.
