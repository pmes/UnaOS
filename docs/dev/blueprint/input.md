# BP-input — HID to focus to ring 3 (read at 1719fe54)

## 1. What it is
- Decoders: xHCI HID (`unaos/crates/kernel/src/drivers/xhci/mod.rs`) and EHCI HID incl. Bluetooth HID and the rMBP Wellspring trackpad (`drivers/ehci/{mod,bthid,finemotion,tpgest}.rs`); and the legacy i8042 PS/2 keyboard (`unaos/crates/kernel/src/drivers/i8042.rs`, ZENBOOKI8042 zenbook-ledger Z3), a TRANSPORT and not a decoder: set-1 scancodes (set 2, controller XLAT) through ONE table at keymap's tail (`keymap::set1_usage`, HID-usage vocabulary) into a synthetic boot report handed to the ONE boot-keyboard decoder `drivers::hidboot::decode_boot_keyboard` (`unaos/crates/kernel/src/drivers/hidboot.rs`, HIDBOOTSHARED rmbp-ledger B982: moved out of EHCI, re-exported by `ehci`; the caller passes its `Transport` — `Ehci`/`Bluetooth`/`Ps2` — and the key lines read `EHCI-HID:` (byte-identical) / `BT-HID:` / `PS2-HID:`) beside EHCI and Bluetooth, drained by the one HID pass (`ehci::service_ehci_hid`), IRQ1 through the opt-in IOAPIC (`ioapic::isa_gsi`, a runtime `vectors::alloc`) else polled.
- Every decoder emits `pal::Event` through ONE seam, `pal::push_event` (`unaos/crates/kernel/src/pal.rs:1341`): `Key`, `KeyUp`, `Mouse`, `MouseAbsolute`, `Button`, `Wheel`, `Action`, `Char` (KEYCHARS B718), plus internal `Timer/None/Unknown` (`unaos/crates/kernel/src/pal.rs:22-80`).
- Chords are a TABLE (`unaos/crates/kernel/src/video/keymap.rs`): role mask + HID usage → `Action`; `keymap::resolve` is the one judge (`unaos/crates/kernel/src/video/keymap.rs:316`).
- Characters per LAYOUT are a TABLE too (`unaos/crates/kernel/src/input/layouts.rs`, declared from keymap.rs): us gb de fr es it se ch, dead keys, AltGr, the Compose tap; ONE seam per HID report, `keymap::layout_report` (`unaos/crates/kernel/src/video/keymap.rs:764`), chosen by Principia's `system.keyboard.layout` / `system.keyboard.compose` (KEYMAPS B704).
- The drain offers each event in order: the login screen (`login::consume_key`), then the focused ring-3 slot (`user_input_route`), else the shell/kernel window.
- Ring 3 reads packed `INPUT_EV_*` words from a per-slot SPSC ring (`SYS_INPUT_POLL` 27 / `SYS_INPUT_WAIT` 28).
