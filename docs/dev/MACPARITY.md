**The legal line (what "without lawyers calling" means here).** Conventions, behaviours, layouts and keyboard chords are not protectable and are what users' hands know; we match those. We do NOT copy: Apple's names (Finder, Dock, Spotlight, Mission Control, Launchpad, Safari …), icons or glyph designs, the San Francisco / Helvetica Neue fonts, system sounds, wallpapers, the exact traffic-light colour values and glyphs, the Apple menu's  glyph, trade dress as a whole. Our own names stay: Quarry, Crystal menu, Lumen, Facet, Settings, the strip/dock.

Legend — **M**: the Mac convention · **U**: UnaOS today (wire / glass evidence) · **Δ**: the gap, one line · **W**: where it folds (the arc or module that owns the surface).

## 1. Menu bar
1. **M** Always present on every screen from the first login; one bar, system-wide; app menus change with the frontmost app. **U** `[strip] paint tenant=menubar` only on a crystal-menu click (flights 24/25); the battery appears on the click (Peter). **Δ** the bar paints with the session, not on demand. **W** R93 DESKTOPBUILT.
2. **M** Left: the system menu, then the app's name in bold, then its menus (File, Edit, View, Window, Help). **U** `[winmenu] app-menu owner=1 name=Console from=declared kind=default` — per-app menus exist with About/Quit. **Δ** no File/Edit/View/Window/Help skeleton with the standard items and chords greyed when unavailable. **W** APPMENU.
3. **M** Right: status items (clock, battery, volume, network, input), each with a menu; clock shows the day and time; items toggle in Settings. **U** clock and battery exist; the battery needs a click to show; no volume/network item. **Δ** status items as a tray with their own menus, settable. **W** MENUBATT, SETTINGS, the strip.
4. **M** The system menu holds About This Mac, System Settings, App Store, Recent Items, Force Quit, Sleep, Restart, Shut Down, Lock Screen, Log Out. **U** "About This Shard", Settings, Sleep, Restart, Shut Down, Log Out. **Δ** Lock Screen (the chord exists, the item does not), Force Quit (Activity exists; no menu route), Recent Items. **W** crystal.
5. **M** Menus open on press, track on hover, close on release or click-away; keyboard navigation with arrows and type-to-select. **U** unmeasured. **Δ** measure, then match. **W** winmenu.

## 2. The dock / taskbar
6. **M** Bottom-centre strip; pinned apps left, running apps show an indicator, minimized windows and the Trash right, a separator between; magnification and auto-hide are preferences; a tile launches or raises. **U** `DOCKPIN tiles=7 pinned=7`, Quarry pinned left "like Finder", shell pinned right, a running indicator (pip). **Δ** Trash tile, the separator, minimized-window thumbnails, auto-hide/magnification/position in Settings, drag-to-reorder, drag-to-pin. **W** dock, DOCKPIN, TRASH.
7. **M** Right-click (or Ctrl-click) a tile: Options (Keep in Dock, Open at Login, Show in Finder), Show All Windows, Hide, Quit. **U** right-click tile → Quit only. **Δ** the menu, and "Open at Login" is the login-items preference Peter asked for (R91). **W** dock, R91.
8. **M** The dock never paints before a session and never blocks input. **U** it painted and swept under the setter (flights 22/23), owed/hidden (24). **Δ** R93. **W** DESKTOPBUILT.

## 3. Windows
9. **M** Title bar: close/minimize/zoom at the left, the title centred, a proxy icon for documents; double-click the title zooms; the window frame is thin; a shadow; rounded corners. **U** title double-click zooms (WINCYCLE), Cmd-M minimizes; the controls' placement and look unmeasured. **Δ** audit the controls' side, order, hover-reveal glyphs, and the title's document name + proxy. **W** wm, theme, UIMETRICS.
10. **M** Resize from any edge/corner; snap/tile to halves via the zoom button's menu; full-screen is a Space; Cmd-` cycles an app's windows; Cmd-Tab the apps (not windows), with a thumbnail switcher; Mission-Control-class overview on a gesture. **U** WINRESIZE, WINSNAP (Cmd-Alt-Left/Right), Cmd-` and Cmd-Tab both exist but Cmd-Tab cycles WINDOWS. **Δ** Cmd-Tab = apps with a visible switcher; an overview gesture; full-screen. **W** WINCYCLE, WINDOWLIST.
11. **M** Focus follows the click; the frontmost window is visibly distinct (title opacity, controls coloured); inactive windows dim their controls. **U** `[wc-fv] focus raise`; FOCUSDEAD (flight 20) left focus on a dead window. **Δ** active/inactive visuals; focus never on a torn-down row. **W** wm, FOCUSDEAD.
12. **M** A new window opens centred (or cascaded) and remembers its size/position per app. **U** fixed geometry (`[quarry] open win=4 surf=1152x720 … at (859,460)`). **Δ** per-app window memory in prefs. **W** PREFSKERNEL, quarry.
13. **M** Windows and input never falter; a stuck app is Force-Quittable; the system never beachballs the whole desktop. **U** R88 (input stalls 1–2.4 s, 16 s HID gaps), WINDOWCAP (R90 done), the flac/mp3 decoder wedges the shell and the wire. **Δ** the stall work; a decoder is a process you can quit. **W** INPUTSTALL, DECJOBHANG, R90.

## 4. Keyboard
14. **M** The standard chords everywhere: Cmd-Q quit, Cmd-W close, Cmd-N new, Cmd-O open, Cmd-S save, Cmd-Z/Shift-Z undo/redo, Cmd-X/C/V, Cmd-A, Cmd-F find, Cmd-, preferences, Cmd-H hide, Cmd-Option-Esc force quit, Cmd-Space search, Ctrl-Cmd-Q lock, Cmd-Shift-3/4/5 screenshots, media keys (F1–F12 brightness/volume/play). **U** SHORTCUTS table: Cmd-/, Alt/Cmd-Tab, Cmd-L / Ctrl-Alt-L lock, F1/F2, F10–F12, Cmd-Shift-3/4, PrtScr, Cmd-M, Cmd-`, Cmd-Alt-arrows, Ctrl-S save in the editor, shell line-editing. **Δ** Cmd-Q, Cmd-W, Cmd-N/O/S as the SYSTEM chords (not per app), Cmd-, for Settings, Cmd-H, Cmd-Option-Esc → Activity, Cmd-Space → a launcher/search, Ctrl-Cmd-Q lock (keep Cmd-L too), Cmd-Shift-5 capture UI. **W** SHORTCUTS, keymap.
15. **M** Text fields everywhere accept the Emacs-style Ctrl-A/E/K and Option-arrow word moves; Tab moves focus between controls; Space toggles; Return activates the default button; Esc cancels. **U** the shell has Ctrl-A/E/U/W; dialogs: unmeasured (`tests notice` says modal=none). **Δ** one text-field widget with the full key set, used by every form (login, settings, lumen, textedit). **W** text, textedit, login.

## 5. Pointer and trackpad
16. **M** Pointer acceleration curve tuned per device; tracking speed in Settings; the pointer never lags or stutters; one-finger tap-to-click optional; two-finger scroll (natural direction preference); two-finger right-click; three-finger drag optional; pinch zoom; swipe between pages/Spaces. **U** TPSCALE flown (flight 19 "mousing is great"), scroll exists, click-and-drag one-handed works, two-finger-hold-and-drag did not (flight 14), tracking speed not in Settings; R88 stalls. **Δ** a Trackpad pane (speed, tap, natural scroll, secondary click, three-finger drag); the gestures; zero stall. **W** ehci hid, SETTINGS, INPUTSTALL.
17. **M** Sliders DRAG and show their value; a click on the track jumps. **U** click jumps; drag arrives as clicks a second apart (SLIDERDRAG). **Δ** press-and-move on every slider. **W** R93, settings widgets.
18. **M** Drag and drop everywhere: files between Quarry windows and onto the desktop, text between fields, a file onto a dock tile to open. **U** unmeasured / absent. **Δ** a system drag protocol (source, payload type, drop target highlight, spring-loaded folders). **W** wm, quarry, clipboard.

## 6. Typography, layout, metrics
19. **M** One system font family at Retina-aware sizes (13 pt body, 11 pt small, 15/17 pt titles), dynamic type; consistent 8-pt spacing; standard control heights; 2× rendering on the 2880×1800 panel (effective 1440×900). **U** DejaVu Sans 13 at `ppi=221 scale=2.5` (UIMETRICS), `[kfont] load … ppi=0` on one boot, Peter: the login font "super huge and blocky" (flight 13, since fixed by QUARRY fonts). **Δ** a metrics table (body/small/title sizes, control heights, paddings) derived from ppi and used by every widget; no literal pixel sizes. **W** UIMETRICS, KERNELFONT, FONTHINT.
20. **M** Text is anti-aliased with subpixel positioning and hinting; never bitmap-scaled. **U** quartzite hinting landed (FONTHINT), `video.font.aa` PASS. **Δ** verify on the glass at 2×; measure glyph edges in a shot. **W** FONTHINT.

## 7. Colour and appearance
21. **M** Light and Dark appearance, auto by time; an accent colour; a highlight colour; translucent materials (vibrancy) behind the bar, dock and sidebars; the wallpaper picker; reduce transparency / increase contrast / reduce motion in Accessibility. **U** one theme ("crispy"), a wallpaper module (WALLP), no dark mode, no accent. **Δ** theme tokens (not literals) for every colour; Light/Dark; accent; translucency where cheap. **W** theme, SETTINGS (Appearance pane).
22. **M** The traffic-light controls and other coloured affordances use the system's palette, not hard-coded hex. **U** unmeasured. **Δ** audit `theme.rs` for literals. **W** theme.

## 8. Feedback, alerts, notifications
23. **M** Alerts are modal sheets attached to their window (or app-modal dialogs) with an icon, a bold message, informative text, and buttons with the default on the right; Esc cancels; they never steal focus from another app's typing. **U** NOTICE windows ("Program stopped", the holocron "started w/pid"), formerly eating typed lines (NOTICEKEYS, fixed), a flash notice that opens and closes. **Δ** a sheet/dialog widget with the standard anatomy; a program's start banner is never a dialog; no focus theft. **W** notice, NOTICEKEYS.
24. **M** Non-modal notifications slide in at the top right, stack, dismiss, and collect in a Notification Center; sounds are optional and quiet. **U** none (R70: "there is no status bar for that so an alert it is"). **Δ** a notification tray; the password/USB/clock events become notifications, not alerts. **W** new module (NOTIFY), menubar.
25. **M** Progress is shown (a determinate bar or a spinner) for anything over ~1 s; the pointer shows a wait cursor only for the app, never the system. **U** "delay in opening when clicked in taskbar" (Peter), no indicator. **Δ** a launch indicator on the dock tile (bounce or pip pulse) and a spinner widget. **W** dock, LAG.
26. **M** Sound: a single quiet alert sound, volume keys with an on-screen bezel, mute. **U** F10–F12 volume keys exist; the test tone screeched for three flights then was fixed (AUDIO8); no bezel. **Δ** the on-screen bezel for volume/brightness; an alert sound of our own. **W** AUDIOKEYS, BRIGHTKEYS, hda.

## 9. The file manager (Quarry) and the desktop
27. **M** Sidebar: Favorites, iCloud/Locations (volumes, network), Tags; the toolbar: back/forward, view switcher (icons/list/columns/gallery), group, share, tag, search; the path bar and status bar optional; column view with a preview column; Quick Look with Space. **U** QUARRY2: columns type/origin, sort by name/size/mtime/type, a tree with Volumes; `columns=FAIL` on flights 24/25; file operations on right-click (QUARRYOPS); Trash exists (TRASH). **Δ** the sidebar/toolbar anatomy; icon and column views; Quick Look (Space previews any sample); search; tags later. **W** quarry, QUARRY2/3.
28. **M** Volumes: the startup disk at the root of the tree; removable media appear on mount and eject by drag-to-Trash or the eject glyph; the root shows Applications, Library, System, Users. **U** R89 (UnaOS + boot, EFI under boot) PASS; R94 (root IS the boot disk; `/apps/LIB` → `/lib`; `/volumes/UnaOS/apps` = `/apps`); R95 (a removable while inserted) unmet — nothing mounts a hot-plugged stick (USBVOL). **Δ** the mount path, the eject affordance, the root layout per R94. **W** VOLUMES2, USBVOL, R94.
29. **M** The desktop holds files (Desktop folder), stacks, and the mounted volumes' icons optionally; double-click opens by type; a file's type and app are visible in Get Info and changeable. **U** screenshots land in /home/una/Desktop (PASS), `assoc` db, FILETYPE/OPENERS 22/24 (WEBM/MP4 owed), SVG opens as text (R94: graphic). **Δ** desktop icons, Get Info, "Open With". **W** desktop, assoc, quarry.
30. **M** Every file type the system claims opens in a viewer that is a real window with standard chords; images zoom/pan; audio/video get a player with transport controls. **U** facet (PNG/GIF/WebP/APNG), fileview/markdown/text/json/csv, WAV plays; FLAC/MP3/OGG/OPUS/M4A stall at demux (DECSTALL); no video player (Stria's). **Δ** a player window with play/pause/seek/volume; the decoder as a quittable process. **W** DECJOBHANG, AUDIOTRACK, Stria.

## 10. Settings
31. **M** System Settings: a searchable sidebar of panes (Appearance, Desktop & Dock, Displays, Keyboard, Trackpad, Sound, Network, Users & Groups, Login Items, Date & Time, Accessibility, Privacy & Security, Battery, General/About); every change applies live; sliders drag; dropdowns for enumerations (resolution, refresh). **U** `SETTINGS: controls=11 tabs=4` — General, Users, Display, About; SETTINGSBUS live; brightness slider click-only; no resolution dropdown; no login items (R91); no trackpad/sound/network/appearance panes. **Δ** the pane list above as the roadmap; each pane folds with its arc (Trackpad with TPSCALE, Sound with hda, Network with USBNET, Login Items with R91, Displays' resolution dropdown with R93). **W** SETTINGS, PREFSKERNEL, R91/R93.
32. **M** Date & Time sets itself from the network and shows the right day; the clock never jumps from a fixture. **U** CLOCKCANNED fixed; no lease yet (USBNET RX stall), the RTC carries the date. **Δ** the lease, then NTP, then a Date & Time pane with time zone. **W** NETCLOCK, USBNET.

## 11. Login, lock, power
33. **M** First boot: a setup assistant (language, keyboard, network, account, password) — one flow, no root prompt; later boots: a login window with user avatars, a password field, Sleep/Restart/Shut Down at the bottom; lock screen on idle with the same look; fast user switching. **U** R77 (root password → create user → desktop), R86 bare setter ≤1 ms keys, boot 2 login screen bare, DIMIDLE blanks at 10 min, SCREENLOCK chord. **Δ** no "root" step shown to the user (the first user is an admin; root stays internal), user avatars, the power row on the login window, the lock screen's look = the login window's. **W** login, INSTALL3, R77.
34. **M** Log Out closes every window and asks about unsaved documents; Shut Down/Restart confirm with a 60 s timer; Sleep is instant; the lid closes to sleep; the power button sleeps/wakes. **U** LOGOUTDESK closes all (R69) PASS; POWER verbs work; no confirm/timer; no unsaved-document ask; lid/sleep unmeasured. **Δ** the confirm dialog with the timer; the unsaved ask; lid → sleep. **W** powerui, login, SMC.

## 12. Accessibility and system behaviours
35. **M** VoiceOver-class screen reading, zoom (Ctrl-scroll), display contrast/reduce motion, sticky/slow keys, pointer size, hover text; everything keyboard-reachable (Full Keyboard Access). **U** none measured. **Δ** start with keyboard reachability (Tab through every control; the login form already is), pointer size, zoom; the rest later. **W** SETTINGS (Accessibility pane), wm focus ring.
36. **M** Spotlight-class search from Cmd-Space: apps, files, settings, math. **U** none. **Δ** a launcher that resolves bare app names (EXECNAME already does) and files by name. **W** EXECNAME, quarry index.
37. **M** The system is silent on the console; diagnostics live in Console.app, never on the user's glass; a kernel panic shows a plain grey message and reboots. **U** QUIETBOOT (R80, 147 lines), the console window shows the boot text on request (R88), the midnight-red panic console. **Δ** the panic screen as a short plain message with a file name and a reboot countdown; the log viewer as an app. **W** fbcon, panic path.
38. **M** Apps are bundles with an icon, a name, a version, an About box; the dock shows the icon; a double-click on a bundle launches. **U** `.ELF` with an app note (EXECNAME: windowed/resident/console), About <app>. **Δ** an icon in the note or beside the ELF; a version; a bundle directory later. **W** EXECNAME, dock.

## 16. The Be inheritance (Peter, 2026-10-06, verbatim)

"one difference i've pointed out is our BeOS alignments. storing settings as attributes made it so easy for user to see what the graphical panels are changing, what is auto-saved, etc. the app's icon. we need to adopt the really handy stuff Be came up with that are more or less lost to the pace of life outside of haiku and we need to reclaim. i just remember thinking especially what a relief it was from windows registry. but really all the OSes, but yeah, fucking so much better than windows registry for developers and users."

What the tree already has: UnaFS carries TYPED ATTRIBUTES on every object with two B+tree indexes (ROADMAP F3, "already exceeds BeFS on one axis"); the file TYPE is the attribute `una:type` (a MIME string, `BEOS:TYPE`'s role, `fs/filetype.rs`); Principia's preferences are ONE TOML file at `<home>/.config/unaos/preferences.toml` behind a bus (SETTINGSBUS), a registry-shaped store a user cannot see from Quarry. The Be rule, as a design (not yet an arc; Peter's word on the shape first):

- **B1 — Settings ARE attributes.** Every preference key lives as an attribute on an OBJECT the user can see in Quarry: `<home>/settings/<domain>` (one small file per domain: `display`, `login`, `sound`, `desktop`, `trackpad`), the keys as typed attributes on it (`system.display.brightness = 7` an int attribute, `system.login.items` a string list). The TOML file goes; prefs_core reads and writes attributes through the same bus. The user opens Get Info on `settings/display` and SEES what the Display pane is changing, live, with the attribute's type and the time it changed — and can edit it there (an attribute edit is a PrefSet). What a panel auto-saves is visible as the attribute's mtime. This is Be's `~/config/settings` + attributes made first-class.
- **B2 — The app's icon, name, version, and kind are attributes on the program.** EXECNAME's app note (windowed/resident/console) becomes `una:kind`; add `una:icon` (a small PNG/SVG blob attribute), `una:version`, `una:name`; the dock, the About box and Quarry read them — no bundle directory needed (BeOS: `BEOS:ICON`, `BEOS:APP_SIG`, `BEOS:APP_VERSION`). An ELF without them gets a generic icon and its file name.
- **B3 — Type and opener are attributes a user can change.** `una:type` exists; add `una:opener` (the preferred program for THIS file, Be's `BEOS:PREFERRED_APP`) so Get Info's "Open with" is an attribute edit, and the type table's default stays the fallback.
- **B4 — Live queries.** The B+tree indexes make `type == image/*` or `name ~ *.md` a QUERY the user saves as a folder (Be's query folders): Quarry shows it, and it updates as files change. Cheap because the indexes exist; a window kind and a tiny query language.
- **B5 — The desktop and Quarry remember through attributes.** A folder's view (icon/list, column widths, sort, window frame) is an attribute ON THE FOLDER (`una:view`), so every folder opens as you left it — Be's Tracker did exactly this and nothing since has.
- **B6 — What is NOT reclaimed:** Be's single-threaded-app-per-window rule and BMessage are ours already in other shapes (the bus); the `/boot/beos` layout is R94's `/system` + `/lib`; BeOS names stay Be's.

Arcs: **ATTRPREFS** (B1; prefs_core + Principia + a Get Info that shows attributes = GETINFO row 29) · **APPNOTE2** (B2; EXECNAME + dock + About) · **OPENWITH** (B3; assoc + Get Info) · **QUERYFOLDER** (B4; Quarry + the indexes) · **FOLDERVIEW** (B5; Quarry). B1 is the one that changes a store everyone reads — it waits on Peter's word on the shape above; B2/B3/B5 are small and ride PREFSUI/QUARRY3/DOCK2.
