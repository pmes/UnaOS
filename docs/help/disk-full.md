# When the disk is full
also: disk full space storage free no space left out of space enospc

When the disk has no room for what you are saving, the save stops and tells you. Everything already on the disk stays whole, including the earlier version of the file you were saving. The computer keeps working.

A notice appears, "Disk full", with the name of the disk and how much space is free. It shows at most once a minute, with a button to open the Trash.

To make room:

1. Empty the Trash. Files in the Trash still take space.
2. Move large files you no longer need to the Trash, then empty it.
3. In the shell window, "df" shows how full each disk is, and "du" shows which folders are largest.

Then save again.
