# Settings
app: settings
settings: login.items
also: preferences options configure control panel system settings tabs search

Settings holds every choice you can make about your computer. Open it from the dock or from the Launcher.

The tabs are in a column on the left. At the top of the column is a search field: type two letters and press Return to jump to a row.

Every choice is saved for your user only and kept between restarts. Nothing in Settings needs the network.

The tabs: General, Users, Display, About, Login Items, Appearance, Trackpad, File Types, Notifications, Accessibility, Privacy, Date & Time, Keyboard, Storage and Security. Each has its own help page; search for its name.

About shows the version, the machine, its processors and memory. Login Items lists the programs that open when you log in. File Types says which program opens each kind of file.
