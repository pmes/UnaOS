# Getting help
app: desktop
also: manual guide how question

This help lives on your computer. It needs no network and no account.

To find a page, press Cmd-Space to open the Launcher and type a few words, for example "disk full" or "time zone". The Launcher shows three kinds of answers together:

- Help pages, like this one.
- Settings rows. Pick one and Settings opens on that row.
- Shell commands, the words you can type in the shell window.

Use the Up and Down keys to choose, and Return to open. A help page opens in its own window. Up and Down scroll it, Tab moves to the next "Open the setting" link, Return follows the link, and Escape closes the window.

In the shell window, "help" lists every command and "help <command>" explains one.
