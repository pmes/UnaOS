# Users and passwords
app: settings
also: user users account accounts password change add delete administrator admin login log out

Each person who uses this computer can have their own user, with their own home folder and their own settings.

The first user made when the computer was set up is the administrator. Settings > Users lists the users, with buttons to add one, delete one, or reset a password.

To change your own password, type "passwd" in the shell window. It asks for the new password twice and never shows it.

Log Out is in the menu. Logging out closes your programs and returns to the login screen.
