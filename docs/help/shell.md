# The shell window
app: shell
also: shell terminal command commands command line console type midden prompt man

The shell window is where you type commands. Open it from the dock.

- "help" lists every command by area. "help <command>" explains one, with examples.
- "man <command>" opens the explanation in a window.
- Tab completes a command or a file name. Up and Down bring back earlier lines.
- Ctrl-C cancels the line you are typing. Cmd-. stops a command that is running. Ctrl-L clears the window.

Every shell command also shows up when you search in the Launcher.
