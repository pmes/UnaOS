# How an update works
also: update upgrade new version install restart reboot system kernel

The system is one file. An update puts a new one beside the old one; it never replaces the old one.

Nothing restarts by itself. The new system starts only the next time you choose Restart. If it does not reach the desktop, the computer starts the old one again on the next start, so an update can never leave you without a working computer.

An administrator stages an update from the shell window with "stage <file>". Programs you add never start by themselves at login unless you list them in Settings > Login Items.
