# Keyboard shortcuts
app: desktop
also: keys chords cmd command key hotkeys

Press Cmd-/ to see every shortcut on the screen at once. In the shell window, the "shortcuts" command prints the same list.

The ones most people use:

- Cmd-Space: the Launcher, to find programs, files, settings and help.
- Cmd-Tab: the next program.
- Cmd-W: close the window. Cmd-Q: quit the program.
- Cmd-C, Cmd-X, Cmd-V, Cmd-A: copy, cut, paste, select all.
- Cmd-L: lock the screen.
- Cmd-Shift-3: a screenshot. Cmd-Shift-4: a screenshot of a part of the screen.
- Cmd-,: the settings of the program you are using.
- F1 and F2: screen brightness. F10, F11, F12: sound off, down, up.
