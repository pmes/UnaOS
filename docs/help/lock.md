# Locking the screen
app: settings
settings: lock.after_idle_min, lock.on_lid, lock.on_sleep
also: lock screen password idle lid sleep away security cmd-l

Locking hides your windows behind the login screen until you type your password. Nothing is closed: when you unlock, everything is where you left it.

- Lock now with Cmd-L, Win-L, or Lock Screen in the menu.
- Settings > Security chooses when it locks by itself: after some minutes with no use (0 means never), when you close the lid, and before the computer sleeps.
