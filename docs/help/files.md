# Files and Quarry
app: quarry
settings: quarry.favorites
also: quarry finder folder folders file manager copy move rename new folder open drag drop get info

Quarry is where your files live. Open it from the dock.

The left side lists your disks and favorite folders. The right side lists what is inside the folder you picked. Double-click a file to open it in the program for its type. Double-click a folder to go into it.

- Drag a file onto a folder to move it there.
- Right-click a file for what you can do with it, such as rename it or move it to the Trash.
- Cmd-I shows a file's details.
- Choose the favorites in the sidebar in Settings > File Types.

Your own files are in your home folder. Nothing is hidden from you there except the Trash, which has its own place in Quarry.

Every change you make in Quarry can be taken back. See "Undo in Quarry".
