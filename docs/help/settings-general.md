# Settings: General
app: settings
settings: audio.volume, audio.mute, pointer.speed, display.wallpaper, dock.position, dock.autohide, dock.pins
also: sound volume mute pointer mouse speed wallpaper background dock general

The General tab holds the sound volume and mute, the pointer, the background picture, and the dock: where it sits, whether it hides until the pointer reaches it, and which programs are pinned to it.

To use your own picture as the background, type the path of a PNG file in the Wallpaper row.
