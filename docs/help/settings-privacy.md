# Settings: Privacy
app: settings
settings: privacy.remember
also: privacy permission permissions ask allow revoke camera answers decisions

When a program asks for something the first time, such as using the camera, you answer once. Your answer is kept, so you are not asked again.

The Privacy tab lists every answer you gave, each with a Revoke button. Revoke one and you will be asked again the next time. Remember my answers decides whether new answers are kept at all.
