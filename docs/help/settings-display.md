# Settings: Display
app: settings
settings: display.brightness, display.idle_min, display.mode, power.lowbat_shutdown_pct, display.font, display.font_size
also: screen brightness blank resolution font size text battery shutdown display

The Display tab holds:

- Brightness of the screen. F1 and F2 change it too.
- Blank screen: minutes with no use before the screen goes dark.
- Resolution of the screen.
- Low battery shutdown: the battery level at which the computer shuts down safely. 0 turns this off.
- Font and Font size for the text on the screen.
