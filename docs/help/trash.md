# The Trash
app: quarry
also: delete deleted remove restore recover empty bin recycle

When you delete a file it goes to the Trash first. It is not gone until you empty the Trash.

Quarry and the shell share one Trash. A file deleted in Quarry and a file removed with the "rm" command land in the same place, and both remember where they came from.

- To get a file back, open the Trash in Quarry and choose Restore. The file returns to the folder it came from.
- Right after you delete something, a notice appears for five seconds with an Undo button.
- To free the space for good, empty the Trash.

In the shell window: "trash ls" lists the Trash, "trash restore <name>" puts a file back, and "trash empty" empties it.
