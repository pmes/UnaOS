Welcome to Aether

The UnaOS browser, running as a ring-3 program on the image.

This page was read off the volume, parsed by html_core, styled by css_core and drawn with font_core — three no_std cores that both rings link. The layout is a CSS2 block and inline formatter written for this program.

What M1 draws

  • Block boxes with margins, padding and borders
  • Inline runs that wrap at spaces, in italic, bold and mono
  • Lists, nested:
    1. numbered items
    2. inside bullets
  • Author colours from a <style> element

Keys

Arrows scroll a line, Page Up and Page Down a window, Home and End the ends. Esc closes the window.

A browser is a document reader first. The rest of the web is layered on that.
fn main() {
  let html = read("welcome.html");
  let dom = parse(&html);
  paint(layout(cascade(&dom)));
}
